# Security Policy

Do not include credentials, private data, PHI, or sensitive reproduction steps
in a public issue.

Report security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/tuva-health/synthetic-data-generator/security/advisories/new).
Include the affected revision, impact, and a minimal reproduction that uses no
real healthcare data.

Ordinary generation defects, schema questions, and documentation corrections
can be reported through public GitHub issues.
